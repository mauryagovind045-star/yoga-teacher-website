# Yogananta — Akshata Halarnkar

Personal yoga & wellness website for Akshata Halarnkar — Goa-based yoga instructor,
national athlete and yoga therapist in training.

**Brand:** Yogananta · Your Infinite Yoga Journey

## Stack

Static site — plain HTML, CSS and JavaScript. No build step.

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

Or simply open `index.html` in a browser.

## Structure

- `index.html` — single-page site (hero, about, credentials, offerings, experience, retreats, gallery, championships, contact)
- `css/style.css` — brand tokens from the Yogananta logo sheet (terracotta / gold / moss / cream, Cormorant Garamond + Jost)
- `js/main.js` — scroll reveals and mobile navigation
- `assets/` — photography extracted from the 2026 portfolio
